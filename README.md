# Tools

Small self-contained tools, one per subfolder, served with GitHub Pages.

| Folder | What it does | URL |
| --- | --- | --- |
| `stock-chart/` | Embeddable stock price chart with range tabs | `https://georgechou.github.io/Tools/stock-chart/?symbol=NASDAQ:NVDA` |

## stock-chart

URL parameters: `symbol` (TradingView `EXCHANGE:TICKER`), `range` (`1d` `1m` `3m` `1y` `5y` `all`), `theme` (`light` or `dark`).
